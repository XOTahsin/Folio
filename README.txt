FOLIO — how to publish (2 minutes)

1. Create a GitHub repo, upload EVERYTHING in this folder (index.html, sw.js,
   manifest.webmanifest and the icons/ folder) to the repo root.
2. Repo > Settings > Pages > Deploy from branch > main > / (root) > Save.
3. Open https://YOURNAME.github.io/REPO/ on your phone.
   - Android (Chrome): an "Install Folio" bar slides up -> tap Install.
   - iPhone (Safari): tap Install -> follow the 3 short steps (Share > Add to Home Screen).
Any HTTPS host works too (Netlify, Vercel, Cloudflare Pages).
